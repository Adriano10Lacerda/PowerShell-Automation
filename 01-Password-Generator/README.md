# Enterprise Password Generator

## Overview

PowerShell-based password generator designed to automate
password creation for IT and Windows administration environments.

## Objectives

- Generate random passwords
- Allow the administrator to define password length
- Validate user input
- Provide a simple command-line interface
- Demonstrate PowerShell automation concepts

## Technologies

- PowerShell 7
- Windows
- Visual Studio Code
